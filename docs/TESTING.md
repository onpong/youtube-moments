## 验证边界

播放器测试使用离线模拟的 YouTube DOM 与真实的浏览器媒体元素，不连接真实 YouTube 服务。它验证扩展逻辑与浏览器 API 的配合，不等于验证所有 YouTube 页面版本、广告样式和账号状态。

尝试访问真实 YouTube 视频时，当前环境返回 ERR_PROXY_CONNECTION_FAILED，因此尚未完成真实网站现场测试。原生侧边栏外框的人工交互以及系统级快捷键触发也仍需安装后检查。Edge 在当前自动化环境启动失败，未完成 Edge 浏览器集成验证；安装包采用 Chrome / Edge 共用的 Chromium 扩展接口。

建议安装后在实际使用的浏览器完成：播放普通视频 → 记录 12:35 → 补充备注 → 关闭浏览器 → 重新打开侧边栏 → 点击 12:35。已经打开的 YouTube 标签页必须先刷新一次。

界面预览图使用明确的示例笔记；安装包不附带预置记录。
